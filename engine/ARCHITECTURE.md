# Roblox Shorts Engine — Architecture & Module Contracts

Offline, deterministic renderer for Roblox-style vertical Shorts (1080x1920). Productions render **30 unique fps**
(the target-style edits are 30 fps content duplicated to 60, with no motion blur); the final mux duplicates to 60 fps.
three.js r187 (WebGL2) in headless Chrome, driven by Node; frames go to ffmpeg; audio and captions are added in a final ffmpeg pass.
Units: **1 three.js unit = 1 Roblox stud** (≈0.28 m). Characters are ~5 studs tall. +Y up. Characters face +Z by default.

## Directory layout
```
Roblox/                      project root = web server root (paths below are URL paths too)
  engine/
    package.json             three, postprocessing, n8ao, puppeteer-core
    lib/                     Node: chrome.mjs (launch), server.mjs (static + frame sink), encoder.mjs (ffmpeg)
    cli/                     Node entry points: render.mjs, still.mjs, preview.mjs, make.mjs (full pipeline)
    runtime/                 Browser ES modules (served at /engine/runtime/)
      index.html, preview.html
      main.js                window.R API used by Node (load, renderFrame, capture loops)
      pipeline.js            renderer + post chain + motion-blur accumulation + I420 packing
      director.js            timeline: picks the active shot for time t, builds sets, evaluates actors/camera/fx
      core/                  math helpers: easing, seeded rng, noise, curves (pure functions)
      world/                 [module] parts, materials, lighting looks, sky, atmosphere, terrain, water, clouds, props
      characters/            [module] blocky rig, faces, clothing, accessories, animation clips + procedural motion
      camera/                [module] camera moves, framing helpers, shake
      fx/                    [module] post-effect parameter animation, finishing shader, particles, transitions
    audio/                   Python: TTS, timing, SFX, music, mix (run with the audio venv)
    captions/                Node: word timings -> styled .ass subtitles (libass) + preview caption data
  assets/library/            reusable assets + manifest.jsonl (CC0/CC-BY, license tracked; music/sfx/models)
    cast/<id>.json           cast presets { header: { id, tags: { role, age, mood, story }, description }, spec }
    kits/<name>.js           environment kits: export meta + default async (S, opts) => { anchors } (S.kit)
    props/<name>.js          procedural props: export meta + default (S, opts) built at the local origin (S.prop)
    attachments.js           character attachments (cast spec `attach: [...]`)
    catalog.json, thumbs/    generated by engine/cli/library.mjs (index | list | search | thumbs)
  productions/<slug>/        one folder per video (script, production.js, timing.json, audio, renders)
```

## Determinism rules (all modules)
- Every visual value is a **pure function of time** `t` (seconds). No `Date.now`, `performance.now`, `Math.random`, `requestAnimationFrame` clocks. Use `core/rng.js` (seeded) and `core/noise.js`.
- Stateful simulations (particles, physics) must be re-computable: simulate from the shot start with a fixed step up to `t`, caching the last state for sequential frames.
- Motion blur renders sub-frames at `t ± dt`; the director clamps sub-frame times to the active shot, so never assume `t` advances monotonically.

## Production format (`productions/<slug>/production.js`)
A JS module (Claude writes it per video). Timing comes from `timing.json` produced by the audio stage (narration word timings), so shots can be anchored to words.
```js
import { defineProduction } from '/engine/runtime/api.js';
import timing from './timing.json' with { type: 'json' };

export default defineProduction({
  fps: 60, width: 1080, height: 1920,
  look: 'day',                                  // world/looks preset name (lighting + sky + post defaults) or object
  cast: {                                       // characters/ spec objects (see contract)
    hero: { skin: 'pastel-yellow', shirt: { color: '#2b6cb0', pattern: 'hoodie' }, pants: { color: '#2f855a' },
            hair: 'messy', hairColor: '#2a1b10', face: 'neutral' },
  },
  sets: {                                       // set builders, called once, cached; S = set builder API (world/)
    plaza: (S) => { S.look('day'); S.ground({ material: 'Brick', color: '#c4705a' }); S.part({ ... }); },
  },
  shots: [
    {
      id: 'hook', set: 'plaza', start: 0, end: timing.words[5].end,   // seconds
      actors: {                                 // characters placed in this shot (cast ids or extras)
        hero: { at: [0, 0, 0], yaw: 180, face: [{ t: 0, expr: 'worried' }, { t: 1.2, expr: 'shock' }],
                anim: [{ clip: 'idle' }, { t: 0.8, clip: 'walk', to: [0, 0, -6], speed: 16 }] },
      },
      camera: { move: 'push_in', target: 'hero.head', from: { dist: 9, height: 1, yaw: 20 }, to: { dist: 5 },
                fov: 45, ease: 'inOutSine', shake: { amp: 0.15, freq: 7 } },
      fx: [{ type: 'flash_white', t: 0, dur: 0.12 }, { type: 'zoom_punch', t: 1.2, amount: 0.08, dur: 0.25 }],
      post: { dof: { focus: 'hero.head', bokeh: 3 }, bloom: 0.4, grade: { saturation: 1.1 } },
      update(ctx, lt) { /* optional custom per-frame logic, pure in lt */ },
    },
  ],
});
```

## Runtime contracts

### director.js (owned by lead)
`createDirector(renderer, production, modules)` → `{ scene, camera, setTime(t), post, shotAt(t), focusPoint }`.
Per `setTime(t)`: find shot (clamped), activate its set (build once via world API), place/pose actors (characters API),
evaluate camera (camera API), evaluate fx (fx API) → writes `director.post` (a plain object the pipeline reads each frame).
`ctx` passed to builders/updates: `{ THREE, scene, set, actors, camera, shot, t, lt, rng, resolve(ref) }` where
`resolve('hero.head')` returns a world-space `THREE.Vector3` for a named anchor (actor part, set anchor, or `[x,y,z]`).

### world/ — `world/index.js` exports
- `createSetBuilder({ THREE, renderer, scene, group, assets })` → **S**:
  - `S.part({ shape: 'block'|'wedge'|'cornerwedge'|'cylinder'|'ball', size: [x,y,z], pos: [x,y,z], rot: [deg x,y,z], color, material, transparency, anchor })` → Mesh (Roblox Part semantics: centered, studs, BrickColor names or hex)
  - `S.model(assetId, { pos, rot, scale })` → Object3D from `assets/library` (glTF), `S.group(name)`, `S.anchor(name, pos)`
  - `S.ground(opts)`, `S.terrain(opts)`, `S.water(opts)`, `S.clouds(opts)`, `S.sky(opts)`, `S.light(opts)` (point/spot/surface), `S.look(name|obj)`, `S.text(opts)` (SurfaceGui-like text on a part)
  - generators: `S.building(opts)`, `S.street(opts)`, `S.tree(opts)`, `S.crowdSpots(opts)`…
  - library: `await S.kit(name, opts)` → `{ anchors }` (dynamic import of `/assets/library/kits/<name>.js`; camera spots are
    anchors `cam_<n>` + `cam_<n>_at`), `await S.prop(name, { pos, yaw, scale, name })` → Group pivoting at `pos`. Set builders
    may be async (the director awaits them). Groups created inside `S.within` pivot in the local frame.
- `materials.js`: Roblox material library (`SmoothPlastic, Plastic, Neon, Glass, Wood, WoodPlanks, Brick, Concrete, Grass, Sand, Metal, DiamondPlate, Fabric, Slate, Marble, Granite, Ice, Cobblestone, Foil, ForceField`) with procedural tiling textures in stud space and roughness/metalness from research/roblox-look.md. Neon = unlit emissive feeding bloom.
- `looks.js`: lighting presets (`day, golden, overcast, night, interior, spooky`) = sun/ambient/hemisphere/env/fog/atmosphere/exposure + post defaults; `applyLook(scene, look, t?)` supports animated time-of-day.

### characters/ — `characters/index.js` exports
- `spec.preset: '<id>'` loads `assets/library/cast/<id>.json` (other fields override, objects merge one level); `spec.attach`
  adds library attachments.
- `createCharacter(spec, { THREE, assets })` → `{ root, parts: { torso, head, lArm, rArm, lLeg, rLeg }, anchors: { head, face, hand_l, hand_r, chest, feet }, setPose(pose), setExpression(name), dispose() }`
- Pose = `{ rootPos: [x,y,z], rootYaw, torso: [rx,ry,rz], head: [...], lArm, rArm, lLeg, rLeg }` (radians, joint-local).
- `animate(character, animTrack, lt, ctx)` evaluates a shot's `anim` list (clips, locomotion along paths/`to` targets with foot-synced stride, blends, holds) → applies pose. Clip library: procedural (`idle, walk, run, jump, fall, wave, point, talk, cheer, cry, scared, shrug, sit, punch, kick, dance, look_around, nod, headshake, facepalm, crouch, climb, fly, swim`, + work/gesture clips `stomp, clap, eat, sew, knit, mouth_cover (hand_over_mouth), palms_up, reach, shake_fist, hop, knock, drag_walk, crouch_low, stand_up`) plus imported CC0 clips (Kenney Blocky/Mini, Quaternius UAL) mapped onto the 6 parts.
- Faces: canvas-drawn expression textures in classic Roblox decal style (original designs): `neutral, smile, grin, happy, sad, cry, angry, shock, worried, smug, scared, evil, sleepy, love, dead, determined, confused, talk_a/talk_o (mouth shapes)`; blink support.
- Original blocky body (6 rigid parts, rounded head). Proportion presets: `classic` (R6-like) and `original` (default; distinct proportions) — legal note in research/assets.md.

### camera/ — `camera/index.js` exports
- `evaluateCamera(spec, lt, shotDur, ctx)` → `{ position: Vector3, target: Vector3, fov, roll }` (director applies to the camera).
- Moves: `static, push_in, pull_out, truck, pedestal, crane_up, crane_down, orbit, arc, track (follow subject), lead (in front of moving subject), flyover/aerial_reveal, top_down, dolly_zoom, whip (fast pan, pairs with fx), handheld, path (explicit keyframes)`; framing helpers (`frame: 'cu'|'mcu'|'ms'|'ws'|'ews'` with subject height → distance); easing from core/easing.js; `shake` (impact / handheld / continuous, seeded noise, amplitude + frequency + decay).

### fx/ — `fx/index.js` exports
- `evaluateFx(fxList, lt, ctx)` → partial post params merged into `director.post` (flash, 2D zoom/punch, blur, grade, vignette, chromatic aberration, glitch, shake2d, speed-ramp is handled by director time remap).
- `createFinishingEffect()` → a pmndrs `Effect` doing grade (exposure/contrast/saturation/temperature/tint/lift/gain), flash overlay, 2D zoom+offset+rotation (screen shake / punch), radial & directional blur, vignette — all driven by `director.post` each frame.
- `recipes.js`: named fx combos `{ type: 'recipe', name, t, ...params }` expanded (once, cached) into plain fx entries:
  hand_reveal, bell_tolls, thunder_clap, monster_entrance, drop_landing (uses the `drop` fx type).
- `particles.js`: deterministic particle systems (smoke, dust, sparkle, confetti, debris, rain, snow, magic) usable from sets/shots.

### pipeline.js post chain (lead; fx module extends)
Accumulation render (motion blur, N sub-frames) → N8AO → DOF + bloom + tone mapping (Khronos Neutral, exposure from look) → SMAA → finishing effect (fx) → grain. All parameters read from `director.post` every frame.

### audio/ (Python, audio venv) and captions/
- `audio/tts_elevenlabs.py` (default, presets in `engine/voices.json`) / `audio/tts.py` (Kokoro) → `audio/narration.wav` + `timing.json` (word timestamps); `audio/sfx_lib.mjs` (shared SFX library), `audio/music.py`, `audio/mix.py` → `audio/mix.wav` (section music, master from `cues.json`, default -12 LUFS / -1 dBTP).
- `captions/ass.mjs timing.json style → captions.ass` (house style: one bold white word, black outline, centred ~lower-middle).

### cli/
- `render.mjs <production> [--preview] [--from s --to s] [--mb N] [--out file]` → video-only MP4 (preview = 540x960, 30 fps, no motion blur, reduced AO).
- `still.mjs <production> --t 1.2,3.4` → PNG stills for visual QA.
- `preview.mjs <production>` → serves the browser preview player (play/pause, scrubber, shot list, captions overlay).
- `make.mjs <production> --stage tts|render|mix|final|all` → the whole pipeline.
